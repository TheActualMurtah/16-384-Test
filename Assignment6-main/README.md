# Assignment 6: Rigid Body Dynamics

Derive the equations of motion for a single-link R arm, a planar RR arm, and a
3D (spherical) pendulum using the Lagrangian, and write them in standard form.
See `assignment6.pdf` for the full writeup and the written questions. There is
no coding portion in this assignment.

## Folder layout

- `assignment6.tex`, `assignment6.pdf`: the writeup (source and compiled).
- `latex/`: the document class and figures for the writeup.

The due date is on Canvas.

## Editing the writeup

`assignment6.tex` is the writeup source; `latex/` holds `16384_doc.cls` and the
figures. You can upload this folder to Overleaf and use `assignment6.tex` as the
project's main file.
